# Revisión de una web universitaria

## Objetivo

Producir una revisión práctica y priorizada. La primera ejecución es de solo lectura.

## Procedimiento

1. Inspecciona la estructura del proyecto y determina cómo se ejecuta.
2. Comprueba que la navegación principal pueda utilizarse con teclado.
3. Revisa etiquetas, foco visible, contraste y textos alternativos.
4. Comprueba el diseño a anchuras aproximadas de 375, 768 y 1280 píxeles.
5. Verifica que título, fecha, lugar, categoría y precio de cada evento sean fáciles de localizar.
6. Revisa los estados vacíos, por ejemplo una búsqueda sin resultados.
7. Comprueba que los controles comuniquen su estado a tecnologías de asistencia.
8. No modifiques archivos durante la primera revisión.

## Formato de salida

Presenta una tabla con:

- prioridad: alta, media o baja;
- problema;
- evidencia;
- impacto para el usuario;
- cambio mínimo recomendado.

Termina con:

1. Las tres mejoras más importantes.
2. Las comprobaciones que no hayas podido realizar.
3. Una petición de aprobación antes de modificar archivos.

## Límites

- No añadas frameworks o dependencias sin aprobación.
- No rediseñes toda la interfaz para resolver un problema local.
- No afirmes haber probado una interacción si solo inspeccionaste el código.
