# Proyecto final

Una posible solución del ejercicio. No es la única respuesta correcta.

## Funcionalidad

- Búsqueda por título, lugar y descripción.
- Filtros generados desde las categorías disponibles.
- Favoritos persistentes.
- Tema claro/oscuro persistente.
- Estado vacío y contador de resultados.
- Controles accesibles y diseño adaptable.

Abre `index.html` directamente o sirve la carpeta con `python -m http.server 8000`.
