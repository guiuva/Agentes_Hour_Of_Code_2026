Anatomía mínima

El archivo SKILL.md

---
name: revisar-web-asociacion
description: Revisa webs universitarias antes de publicarlas.
---

# Revisión
1. Inspecciona sin modificar.
2. Comprueba teclado, contraste y vista móvil.
3. Presenta problemas ordenados por prioridad.
4. Espera aprobación antes de editar.

Seguridad

Cinco hábitos antes de confiar

  • Trabajar con Git o una copia recuperable
  • No introducir secretos ni datos personales
  • Revisar comandos destructivos
  • Limitar el alcance de cada tarea
  • Verificar el resultado personalmente
